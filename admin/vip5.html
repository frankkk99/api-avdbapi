Local runner

คำสั่งสำหรับ VPS / aaPanel

SERVICE ROLE ONLY

หน้าเว็บทำหน้าที่สร้างและดูสถานะ Run ส่วนการดึง 10,262 หน้าให้รันจากเครื่องที่มี Chromium เพื่อไม่ให้หมดเวลาแบบ serverless

cd runner
npm install
SUPABASE_URL="https://YOUR_PROJECT.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="เก็บไว้ในเครื่อง runner เท่านั้น" \
START_PAGE=1 END_PAGE=10262 npm start

ถ้าหยุดกลางทาง ให้ใช้ RUN_ID=<run-id> เดิมเพื่อ resume จากหน้าล่าสุด
